| Роль          | Права роли                              | Группы пользователей        |
|---------------|-----------------------------------------|-----------------------------|
| cluster-admin | Полный доступ ко всем ресурсам          | Администраторы кластера     |
| developer     | Создание/изменение ресурсов в namespace | Разработчики                |
| viewer        | Только чтение ресурсов                  | Бизнес-аналитики, менеджеры |
| auditor       | Чтение всех ресурсов (включая секреты)  | Специалист по ИБ            |
