#### Обоснование выбора разделов проверочного листа

**Ключевые проблемы PropDevelopment:**

* Нарушен контроль данных - разрозненные точки регистрации, нет координации
* Небезопасные API интеграции с партнерами
* Инциденты доступа - клиенты видят чужие данные в ЛК
  *Блокировка BI/AI развития из-за проблем с управлением данными

**Приоритеты для аудита:**

* Первая очередь: Безопасность данных + Управление доступом
* Вторая очередь: Управление инцидентами + API интеграции
* Третья очередь: Защита инфраструктуры + Физическая безопасность
